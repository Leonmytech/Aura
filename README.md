# Aura
Aura è un music player nativo per macOS in SwiftUI: sfoglia la tua libreria locale per album e artisti, ascolta MP3, FLAC, AIFF, WAV e M4A, con visualizer, sfondo animato Metal che reagisce alla musica, mini player e icona nella barra dei menu. Leggero, elegante, universale (Apple Silicon + Intel).
